# Интернет магазин.
## Описание проекта.
### Это учебный проект, демонстрирующий работу по созданию интернет магазина. В данный момент в нем практически ничего нет.

- Отображение списка товаров.
- Просмотр отдельного товара.
- Просмотр товаров по категориям.
- Страница контактов с формой обратной связи и отображением контактных данных из админки.
- Страница добавления нового товара.
- Кастомная команда для заполнения базы тестовыми данными.
- Использование фикстур и базового шаблона.

## Для использования его функционала необходимо:
1. Установить poetry:  
   ```bash
   poetry install
   ```
2. Установите зависимости:
   ```bash
   poetry add requests
   ```
3. Запустите локальный сервер разработки:
   ```bash
   python manage.py runserver
   ```
4. Перейдите в браузере по адресу `http://127.0.0.1:8000/`.
