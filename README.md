## Для использования его функционала необходимо:
1. Установить poetry:  
   ```bash
   poetry install
   ```
2. Установите зависимости:
   ```bash
   poetry add requests
   ```
3. Запустите локальный сервер разработки:
   ```bash
   poetry run python manage.py runserver
   ```
4. Перейдите в браузере по адресу `http://127.0.0.1:8000/`.
