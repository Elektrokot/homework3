# Интернет магазин

## Описание проекта

### Это учебный проект, демонстрирующий работу по созданию интернет магазина. В проекте реализованы:

- Отображение списка товаров (с пагинацией).
- Просмотр отдельного товара.
- Просмотр товаров по категориям.
- Страница контактов с формой обратной связи и отображением контактных данных из админки.
- Страница добавления нового товара.
- Кастомная команда для заполнения базы тестовыми данными.
- Использование фикстур и базового шаблона.
- **Новое:** Приложение блога с полным CRUD (создание, чтение, обновление, удаление).
- **Новое:** Увеличение счётчика просмотров статьи.
- **Новое:** Фильтрация опубликованных статей.
- **Новое:** Перенаправление после редактирования статьи.
- **Новое:** Управление статьями через админ-панель.
- **Новое:** CRUD для продуктов с использованием `django.forms`.
- **Новое:** Валидация форм: запрещённые слова, отрицательная цена, формат и размер изображения.
- **Новое:** Стилизация форм с использованием Bootstrap.

## Установка и запуск

1. Убедитесь, что у вас установлен Python 3.9+.
2. Установить poetry:  
   ```bash
   poetry install
   ```
3. Установите зависимости:
   ```bash
   poetry add requests
   ```
4. Сделайте миграции:
   ```bash
   python manage.py migrate
   ```
5. Запустите локальный сервер разработки:
   ```bash
   python manage.py runserver
   ```
6. Перейдите в браузере по адресу `http://127.0.0.1:8000/`.

## Заполнение базы тестовыми данными

Для заполнения базы данных тестовыми данными из фикстур выполните:

```bash
python manage.py add_products
```
